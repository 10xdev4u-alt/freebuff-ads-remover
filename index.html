06 / INSTALL
Get started

Five minutes. Zero ads.

Install once. The remover patches the app, loads on every launch, and stays out of your way.

$ git clone https://github.com/10xdev4u-alt/freebuff-ads-remover.git
$ cd freebuff-ads-remover && npm install && npm run build
$ ./scripts/launch-freebuff.sh
# shield goes live · dashboard opens · ads die
01 · CLONE & BUILD
Clone & build
Clone the repo, run npm install and npm run build. dist/ is what the app loads.
02 · PATCH
Patch (automatic)
The launcher repacks app.asar with the loader baked in. app.asar.orig is always kept.
03 · LAUNCH
Launch & verify
Start Freebuff. The shield activates, the dashboard goes live, every ad route blocked.
Does this break Freebuff updates?

No. The patch only injects a require() into main.cjs. Freebuff's own updater still works; the launcher re-patches automatically.

Is my data sent anywhere?

No. The remover is fully local. It blocks telemetry endpoints and never phones home itself.

How do I uninstall?

mv app.asar.orig app.asar. That's it. No residue, no background process.
