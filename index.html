Mechanism

Why patching is the only way in.

FAQ

Asked, answered.

Do I need to do anything when Freebuff updates?

No. Restart the app from your icon — the launcher adopts the newer payload and re-patches it by itself.

How do I prove blocking is active?

Launch with --remote-debugging-port=9222 and run node scripts/verify-remover.mjs — expect PASS. Or set "logLevel": "debug" and watch Blocked ad request: lines in the extension log.

Does it modify my Freebuff install?

No. The AppImage file is never touched — the patch applies to an extracted copy under /tmp, with the original archive preserved as app.asar.orig.

Does the extension phone home?

No. Zero network calls of its own — local filtering, CSS hiding, file logging. See SECURITY.md.

How do I turn off just the dashboard?

Set "dashboard": false in the config — blocking keeps working and the badge unmounts.
